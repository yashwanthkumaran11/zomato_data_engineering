# 🍽️ Zomato Data Engineering Project

A Zomato-inspired Data Engineering project focused primarily on **SQL, MySQL, relational databases, and data analysis**.

The project simulates a Zomato-like food ordering workflow where transactional data is stored in a MySQL database and analyzed using SQL to derive meaningful insights.

---

## 📌 Project Overview

This project demonstrates an end-to-end flow of collecting transactional data through a web application, storing it in a relational database, and performing SQL-based data analysis.

The main focus of the project is **SQL data analysis**, including relational database concepts, joins, aggregations, filtering, grouping, and data transformation.

A Python Flask application with REST API endpoints is used as the supporting application layer for the ordering workflow.

## 🗄️ Database

**Database Name:** `zomato`

### Database Structure

```text
zomato
│
├── customers
├── orders
├── items
├── categories
├── order_items
└── payments
```

### Table Description

| Table | Description |
|---|---|
| `customers` | Stores customer information |
| `orders` | Stores order details |
| `items` | Stores food item information |
| `categories` | Stores food categories |
| `order_items` | Stores items associated with orders |
| `payments` | Stores payment information |

## 📊 SQL Data Analysis

The project includes 12 SQL analysis queries covering different aspects of the transactional data.

### 1. Total Revenue

Calculates the total revenue generated from ordered items.

### 2. Revenue by Item

Analyzes the revenue generated by each food item.

### 3. Revenue by Payment Method

Analyzes revenue based on different payment methods.

### 4. Revenue by Date

Analyzes revenue generated across different dates.

### 5. Orders & Revenue by Customer

Analyzes the total number of orders and revenue generated by each customer.

### 6. Items by Category

Analyzes the quantity of items ordered across different food categories.

### 7. Orders by Payment Status

Analyzes orders based on their payment status.

### 8. Customers with Most Orders

Identifies customers with the highest number of orders.

### 9. Revenue by Category

Analyzes revenue generated by different food categories.

### 10. Items in Specific Order

Retrieves the items, quantities, and prices associated with a specific order.

### 11. Customer Details with Orders

Combines customer information with their order details.

### 12. Revenue by Customer

Analyzes the total revenue generated by individual customers.
